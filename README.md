# UI Template Collection

## GitHub Team Collaboration Project

A collection of modern, interactive web UI projects developed as part of the **UI Template Collection Hackathon**.

The project demonstrates modern frontend design, interactive user experiences, responsive layouts, and GitHub-based team collaboration using branches, commits, pull requests, code reviews, and merges.

---

## Projects

### 🚗 AUTO//VAULT

**Automotive Luxury Showcase**

A premium interactive automotive website featuring luxury and performance vehicles.

**Highlights**

* Multi-brand automotive showcase
* Vehicle search and filtering
* GT3 Garage
* Vehicle configurator
* Interactive model pages
* Responsive premium UI
* Modern animations and transitions

---

### ✈️ AERO//CONTROL

**Airport Operations & Passenger Experience**

An interactive airport management and passenger-experience interface.

**Highlights**

* Passenger Mode
* Operations Mode
* Flight search
* Arrivals and departures
* Airport map
* Interactive gates
* Digital boarding pass
* Baggage tracking
* Security queue information
* Airport alerts
* Passenger journey tracking

---

### 🕰️ TIME//CAPSULE

**Interactive Technology Museum**

A digital museum experience exploring the evolution of technology through time.

**Highlights**

* Interactive technology timeline
* Historical technology artifacts
* Explore-by-era interface
* Then vs Now comparisons
* Interactive statistics
* Future technology exploration
* Museum-style presentation
* Responsive interface

## GitHub Collaboration Workflow

The project follows the GitHub collaboration workflow:

```text
Fork
  ↓
Branch
  ↓
Commit
  ↓
Push
  ↓
Pull Request
  ↓
Code Review
  ↓
Merge
```
