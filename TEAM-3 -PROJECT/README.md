# COLOR / DATA — Analytics UI Collection

## Required UI Templates
1. User Analytics
2. Customer Analytics
3. Product Analytics

## Visual Reference
The landing page follows the requested visual direction: large editorial heading, three bold colour blocks, strong black borders, simple geometric charts and different visual treatment for each analytics topic.

## Colour System
- User Analytics — vivid coral/red
- Customer Analytics — electric blue
- Product Analytics — bright yellow
- Background — warm off-white
- Team/footer — deep black

## UI Patterns
User: activity bars and engagement.
Customer: circular health score and retention.
Product: funnel-style visual and adoption metrics.
