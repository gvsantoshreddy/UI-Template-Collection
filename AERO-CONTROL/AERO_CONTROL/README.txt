AERO//CONTROL — Airport Super App

A premium airport passenger-experience + operations UI built for the UI Template Collection Hackathon.

Files:
- index.html — complete app interface
- style.css — responsive visual system
- script.js — flights, filters, search, modes, journey, modal and live clock

Run:
1. Extract the folder.
2. Open AERO_CONTROL in VS Code.
3. Open index.html with Live Server, or open index.html directly in a browser.

No image assets are required. The airport map/radar are CSS-based so the project remains self-contained and avoids broken external images.
