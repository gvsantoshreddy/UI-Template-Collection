TIME//CAPSULE — Interactive Technology Museum

Student project: HTML + CSS + JavaScript

WHAT IT IS
TIME//CAPSULE is an interactive digital museum about the evolution of everyday technology. It is intentionally designed around interaction rather than a normal portfolio/e-commerce layout.

FEATURES
- Interactive 1920 → 2035 timeline
- Keyboard arrow navigation through eras
- Era-specific museum records and facts
- Archive with search and filters
- Historical artifact imagery from Wikimedia Commons for selected objects
- Artifact detail modal records
- Then/Now comparison slider
- Animated statistics
- 2035 Future Lab: choose 3 technologies and generate a speculative scenario
- Personal reflection: create your own museum label
- Responsive design
- Optional subtle browser-generated ambient tone

RUN
Open index.html directly, or use VS Code Live Server.

IMAGE / SOURCE NOTE
Selected historical images are referenced from Wikimedia Commons using Special:Redirect/file URLs. Check the linked Commons file page for the applicable license/attribution before public or commercial deployment. The project intentionally does not use AI-generated imagery.

IMPORTANT
The 2035 section is speculative by design. It is a creative future-building interaction, not a factual prediction.

IMAGE NOTE
The archive now uses bundled SVG artifact illustrations for reliable offline display. External image failures are protected by a local fallback, so broken-image icons should not appear.
